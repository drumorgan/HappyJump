Sign in to Faction Events

Faction Events keeps your Torn API key encrypted on our server so you don't have to re-enter it every visit. Sign in once and your counts refresh automatically when anyone loads the event page.

No key? Click here to create a Custom Key — it only needs your name, level, faction, log, calendar, and attacks. Your key is encrypted server-side and tied only to Faction Events; signing out deletes it. Attack-tracking events need the attacks scope; if you minted a key before that was added, just create a new one with the link above.

Create a New Event

Pick what you're tracking, set the start date and how long the event runs. You'll get a shareable link to send to your faction.

Attack events show three columns per player: # Attacks, Respect Gained (default sort) and Avg Respect / Attack, plus the single best-respect hit. Requires every participant's Custom Key to include the attacks scope — anyone without it stays at 0 until they re-mint.

Events start at 10:00 TCT (game time) on the date you pick and run for the duration in hours. Default 48h; cap 720h (30 days). After creating, you (and every joiner) pick your own personal start time from the leaderboard page.

Attack events run from the exact start time you set, in TCT (game time), for the chosen duration. Every participant shares the same window — there's no per-player slot picker.

Members of these factions who've signed in to Faction Events get added automatically — they don't have to visit the share link themselves. Your own faction is pre-added; type to search for and add more.
